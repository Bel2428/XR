Paradigma de Realidad Extendida (XR)

XR agrupa las tecnologías que combinan o amplían la realidad. Recorre el espectro con los botones de arriba:

  • Real: solo el entorno físico
  • RA: real + información virtual
  • RM: real + objetos virtuales integrados
  • RV: entorno totalmente virtual

Usa la cámara y el giroscopio. Acepta los permisos cuando el navegador los pida. Mueve el dispositivo para mirar alrededor (en PC, arrastra).
